# Viva / Demo Flow

1. Register a student and optionally enter their course.
2. Upload a genuine NPTEL certificate. Show correct ID, name, course and QR consistency.
3. Upload a Saylor certificate. Show issuer recognition through Saylor wording/link and certificate code.
4. Upload Analytics Vidhya. Show issuer template recognition and fields without requiring a QR.
5. Upload Infosys Springboard. Show Verifiable Credential QR parsing.
6. Upload NIELIT. Show government issuer and certificate number extraction.
7. Create a modified copy of a certificate by changing the visible name while keeping the original QR/ID. Upload both. The second submission should produce a conflict if the same certificate ID is retained.
8. Open the downloadable report.
9. Open Audit Logs.
10. Open Dashboard and show issuer distribution and verdict counts.
11. Open Admin Panel and add a reference record.
12. Open `/api/blockchain/verify` to demonstrate chain integrity.
